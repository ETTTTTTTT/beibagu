下载本目录任意 `.json`，在 IDEA / VS Code 插件里点 **导入题目**（合并）或 **导入题库**（替换）即可。

## 怎么导入

1. 打开插件「面试背题」
2. 点 **导入题目**（往现有题库里加）或 **导入题库**（整库替换）
3. 选中本目录某个 `.json`

## 自制题库

最小可用结构（UTF-8 JSON）：

```json
{
  "meta": {
    "title": "我的自制题库",
    "questionCount": 1
  },
  "questions": [
    {
      "id": "my-001",
      "type": "short",
      "question": "题干写这里",
      "answer": "参考答案写这里",
      "analysis": "可选：解析 / 易错点",
      "categories": ["一级分类 / 二级分类"]
    }
  ]
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `question` | 是 | 题干；也认 `title` / `stem` |
| `answer` | 建议 | 参考答案；字符串或字符串数组都行 |
| `id` | 否 | 不填会自动生成 |
| `type` | 否 | 默认 `short`（简答） |
| `analysis` | 否 | 解析 |
| `categories` | 建议 | 分类路径，推荐 `父类 / 子类`；也可用单个 `category` |

也可以直接丢 **题目数组**（没有外层 `meta`），插件同样能识别。

复制 `99-自制题库模板.json` 改两道题练手最快。
